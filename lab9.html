Step 1

Read the price function

Don't type it. It's already in your starter code below. Just read it.



    
    
      
  • This is all stuff you know. A function with a return value from Lesson 4, and the body is if / else from Lesson 5.
    • 
      
  • var price = 0.0 — money needs decimals, so price is a Double. Every price is written 9.0, not 9, for the same reason.
    • 
      
  • Double(quantity) — casting, from Lesson 1. quantity is an Int because it comes from a Stepper, and Swift won't multiply a Double by an Int.
    • 
      
  • Notice the order. Quantity is multiplied in before delivery is added. Three pizzas costs three times as much, but you still only pay for delivery once.

That's the delivery fee. It gets added after the quantity multiply, not before.
